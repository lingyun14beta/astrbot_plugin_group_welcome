# 🎉 Group Welcome · 入群欢迎插件

> 适用于 AstrBot 的入群欢迎插件，支持欢迎图片、AI 个性化欢迎、群专属欢迎语、私聊群规、黑白名单管理。


---

## 依赖说明

- 支持 **OneBot 11**（aiocqhttp）与 **QQ 官方机器人**（AstrBot 的 `qq_official` / `qq_official_webhook` 适配器）。
- 官机适配按 AstrBot 4.30 的适配器行为实现（插件以打补丁方式接入，不修改 AstrBot 本体）；OneBot 场景建议 v4.12.0+，**官机场景要求 v4.29.0+**。
- 若机器人启动后欢迎未触发，请尝试**重启机器人**或**重载插件**（官机首次安装后必须重启）。

---

## 功能特性

- **群欢迎模板库**：可在后台维护多套欢迎模板，按群号匹配，命中群优先使用模板配置；模板未填写的项自动回退到全局配置。
- **群专属欢迎语**：可为不同群单独设置欢迎内容，未设置的群使用全局默认。
- **AI 个性化欢迎**：调用 AstrBot 配置的大模型，根据新成员昵称生成一句定制欢迎语，支持指定模型、失败重试。
- **欢迎图片池**：可配置多张欢迎图片，每次入群**随机发送一张**，支持网络 URL 或本地路径。
- **群人数统计**：欢迎语中可追加"你是当前群里第 X 位成员"。
- **私聊发送群规**：新人入群后尝试私聊发送群规内容（默认关闭，防风控）。
- **黑白名单**：灵活控制哪些群启用欢迎功能。
- **防刷屏冷却**：同一用户短时间内重复入群不重复触发。
- **冷却数据持久化**：重启后冷却记录不丢失。
- **QQ 官方机器人支持**：自动为 qq-botpy 补上 `GROUP_MEMBER_ADD` intent 与事件解析，官机入群同样能收到欢迎。

---

## 安装

将插件文件夹（含 `main.py`、`_conf_schema.json`、`metadata.yaml`）放入 AstrBot 的 `data/plugins/` 目录，重启 AstrBot 即可。

---

## QQ 官方机器人（官机）支持

插件同时支持 OneBot 11（aiocqhttp）与 QQ 官方机器人（AstrBot 的 `qq_official` / `qq_official_webhook` 适配器）。

### 前提条件

- 机器人已在 QQ 开放平台完成接入，并开启群聊能力（AstrBot 平台配置中的「群聊 / C2C」开关）。
- **AstrBot ≥ v4.29.0**。更低的版本缺少群主动消息 / 主动消息 Markdown 渲染 / `At` 转换，会出现欢迎发不出去或 @ 丢失；插件启动时会在日志里显式告警。
- **机器人已开通「主动消息」权限**。官机入群事件没有可用于被动回复的 `msg_id`，欢迎语只能以主动消息发出；未开通时接口返回 `40034105`，日志中会给出明确提示。
- 机器人已订阅群成员事件（`GROUP_MEMBER_ADD`，intent `GROUP_MEMBER_EVENT`）。若开放平台后台需要手动勾选事件，请一并开启。

### 使用方式

1. 安装 / 更新插件后**重启 AstrBot**（入群事件依赖启动时的 intent 协商，WebUI 热重载不生效）。
2. 保持默认配置「🛰️ QQ 官方机器人支持」开启。
3. 在群里 `@机器人 /welcome status`，可看到当前群的 `group_openid`；白名单、黑名单、模板库都填这个值，而不是 QQ 群号。
4. 通过 `/welcome set` 或后台配置欢迎语即可。

### 与 OneBot 11 的差异

| 能力 | OneBot 11 | QQ 官方机器人 |
|:--|:--|:--|
| 触发事件 | `group_increase` 通知 | `GROUP_MEMBER_ADD` |
| 新成员昵称 | 群名片 / 昵称 | 需成员信息接口，未开放时使用「官机昵称占位」 |
| @ 新成员 | 原生 at 段 | Markdown `<qqbot-at-user />`，依赖 Markdown 发送 |
| 群人数 | `get_group_info` | 群信息接口 `group_member_num`，取不到则跳过 |
| 欢迎消息类型 | 普通群消息 | **主动消息**（每群每天 1000 条上限） |
| 私聊群规 | 私聊消息 | 单聊主动消息，用户可关闭「允许主动发送」 |
| 群标识 | QQ 群号 | `group_openid` |

> 官机的 @ 只在 Markdown 消息中渲染。插件发送欢迎语时会强制 Markdown；若平台拒绝 Markdown 并回退纯文本，@ 标记可能显示为原始文本，但不影响消息送达。
>
> 官机的富媒体消息无法与 Markdown @ 混排。公网图片（`http(s)://`）会以 Markdown 内嵌图片随欢迎语一起发出，**每次入群只消耗 1 条主动消息**；本地路径图片无法内嵌，会拆成第二条富媒体消息。

## 后台配置（WebUI）

进入 AstrBot 后台 → 插件配置页面，可设置以下项目：

| 配置项 | 说明 | 默认值 |
|:--|:--|:--|
| 🎉 全局默认欢迎语 | 支持变量 `{name}`（昵称）、`{count_text}`（第几位成员） | 内置默认语 |
| 📦 群欢迎模板库 | 按群号匹配，命中群优先使用模板配置（详见下方优先级说明） | 空 |
| ✅ 白名单群号 | 每行一个群号，填写后只有这些群触发欢迎 | 空 |
| 🚫 黑名单群号 | 每行一个群号，白名单为空时生效 | 空 |
| 📊 开启群人数统计 | 欢迎语末尾追加成员序号 | 开启 |
| 📩 开启私聊群规 | 新人入群后尝试私聊发送群规 | 关闭 |
| 📜 群规内容 | 私聊发送的具体文字 | 内置示例 |
| 🤖 开启 AI 个性化欢迎 | 调用大模型生成一句定制欢迎语 | 关闭 |
| 🧠 AI 模型提供商 | 指定用于生成欢迎语的模型，留空使用系统默认 | 空（系统默认） |
| 🔄 AI 重试次数 | AI 生成失败后的重试次数，0 表示不重试 | 0 |
| 📝 AI 提示词 | 指导 AI 生成内容，支持 `{name}` 变量 | 内置提示词 |
| 🖼️ 欢迎图片池 | 可填多张图片 URL 或本地路径，每次随机发送一张 | 空（不发送） |
| ⏱️ 防刷屏冷却（秒） | 同一用户重复入群的最小触发间隔 | 300 秒 |

### 模板库优先级说明

配置优先级从高到低为：

1. **模板库**：`group_ids` 中包含当前群的模板。模板中的开关项（如群人数统计、私聊群规、AI欢迎）始终以模板为准；文本/图片列表项留空时回退到下一级。
2. **群专属欢迎语**：通过 `/welcome set` 指令设置的旧版群欢迎语。
3. **全局默认配置**：上方表格中的全局配置项。

> 旧版配置（白名单、黑名单、群专属欢迎语等）完全兼容，不配置模板库时行为与旧版一致。

> ⚠️ **请勿在 WebUI 中手动修改「群专属配置」字段**，该字段由系统自动维护，手动编辑可能导致 JSON 损坏。请使用 `/welcome set` 指令进行配置。

## 指令列表

所有指令需要**管理员权限**。指令前缀默认为 `/`，请根据你的 AstrBot 配置调整。

> 群标识：OneBot 11 填 QQ 群号；QQ 官方机器人填 `group_openid`（可在群内发送 `/welcome status` 查看）。

### 欢迎语设置

| 场景 | 指令 | 说明 |
|:--|:--|:--|
| 群聊 | `/welcome set 欢迎 {name} 加入！` | 设置本群专属欢迎语 |
| 群聊 | `/welcome set reset` | 清除本群设置，恢复全局默认 |
| 群聊 | `/welcome set show` | 查看本群当前欢迎语 |
| 私聊 | `/welcome set <群号> 欢迎 {name} 加入！` | 为指定群设置欢迎语 |
| 私聊 | `/welcome set reset <群号>` | 清除指定群设置 |
| 私聊 | `/welcome set show <群号>` | 查看指定群当前欢迎语 |

### 状态查询

| 指令 | 说明 |
|:--|:--|
| `/welcome status`（群聊） | 查看插件状态 + 本群欢迎语及来源 |
| `/welcome status`（私聊） | 查看插件状态 + 已自定义群的数量 |
| `/welcome status <群号>`（私聊） | 查看插件状态 + 指定群欢迎语 |

### 功能开关

| 指令 | 说明 |
|:--|:--|
| `/welcome count on/off` | 开启 / 关闭群人数统计 |
| `/welcome rules on/off` | 开启 / 关闭私聊群规 |
| `/welcome ai on/off` | 开启 / 关闭 AI 个性化欢迎 |

### 黑白名单

白名单不为空时，只有白名单内的群会触发欢迎；白名单为空时，黑名单内的群不触发欢迎。

| 指令 | 说明 |
|:--|:--|
| `/welcome wl add <群号>` | 加入白名单 |
| `/welcome wl del <群号>` | 移出白名单 |
| `/welcome wl list` | 查看白名单 |
| `/welcome bl add <群号>` | 加入黑名单 |
| `/welcome bl del <群号>` | 移出黑名单 |
| `/welcome bl list` | 查看黑名单 |

## 常见问题

**Q：开启了私聊群规，但新人没收到私聊？**

新成员可能关闭了"允许陌生人发起临时会话"，或当前平台风控限制了临时会话。建议将重要群规直接写在群欢迎语中。

**Q：AI 欢迎开启了，但没有生效？**

请确认：① 已执行 `/welcome ai on`；② AstrBot 已配置可用的大模型（平时 @ 机器人能正常回复即可）；③ 若指定了模型，确认该模型 ID 填写正确。

**Q：如何为不同群指定不同的 AI 模型？**

可在"群欢迎模板库"中为指定群号单独配置"AI 模型提供商"，模板配置优先于全局；未配置模板或模板留空的群使用全局设置。

**Q：配置了欢迎图片但群里没显示？**

请确认图片 URL 可直接在浏览器打开，且 OneBot 客户端能正常访问。部分客户端可能不支持某些图片格式或过大的文件。图片池中每张图片都会随机发送，若某张无法访问会正常发送其余图片。

**Q：官机上新成员入群后没有任何反应？**

请依次检查：① 插件版本 ≥ 2.6.0 且安装后**重启过 AstrBot**；② AstrBot 平台配置中已开启群聊；③ 机器人有「主动消息」权限（无权限时日志会出现 `40034105`）；④ 白名单 / 黑名单填的是 `group_openid` 而不是 QQ 群号；⑤ 日志中是否出现 `QQ 官方机器人入群事件监听已成功注册`。

**Q：官机欢迎语里的昵称不对 / 显示成「新朋友」？**

官方群成员信息接口尚未全量开放，取不到昵称时会使用插件配置中的「🏷️ 官机昵称占位」（默认「新朋友」）；填写昵称可直接调整该配置。

**Q：官机的 @ 没有变成蓝色提醒？**

@ 依赖 Markdown 消息渲染。插件已强制使用 Markdown 发送欢迎语；若平台拒绝 Markdown 回退为纯文本，@ 标记会以原始文本出现。可在 AstrBot 平台配置中保持 Markdown 开启（默认开启）。

## AI 功能使用声明

启用"AI 个性化欢迎"功能即表示您同意以下条款：

1. **数据传输**：本插件仅将新成员的**公开昵称**发送给您配置的大语言模型，不涉及 QQ 号或其他私密信息。
2. **内容免责**：AI 生成内容由您所配置的模型提供，插件开发者不对内容的准确性或适宜性作任何保证。
3. **费用说明**：启用此功能将消耗您配置的模型服务的 API 调用额度，请根据实际需求酌情使用。
